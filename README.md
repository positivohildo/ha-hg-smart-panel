# Repositório de Add-ons HG Smart Home Panel

Repositório oficial de Add-ons para Home Assistant do painel de parede **HG Smart Home Panel**.

## Add-ons inclusos

* **[HG Smart Panel Gateway](hg-smart-panel-gateway/)**: Gateway local na porta 8090 com cache e redimensionamento de câmeras, temporizador de eletrodomésticos (Airfryer) e integração com Alexa da Sala.

## Como Adicionar este Repositório no Home Assistant

1. No Home Assistant, acesse **Configurações → Add-ons → Loja de Complementos**.
2. No menu superior direito (3 pontinhos), clique em **Repositórios**.
3. Adicione o endereço:
   ```
   https://github.com/positivohildo/ha-hg-smart-panel
   ```
4. Atualize a loja e instale o **HG Smart Panel Gateway**.
